# My Glossary

Add each day's new words here, in your own words.

## Kickoff
- **HTML**: The structure of a page (walls of a house)
- **CSS**: The decoration of a page (decoration in a house)
- **JavaScript**: The brain behind a page (The structure of a house)

## Week 1 Monday (HTML) 
- **element**: a fundamental unit that is a building block.
- **tag**: markers that end and start an element.
- **attribute**: characteristic/piece of metadata that is assigned to a specific element.

## Week 1 Tuesday (CSS) 
- **selector**: tells which elements to style and target.
- **property**: layout feature you want to alter.
- **value**: style instructions that is a assigned to a CSS property.

## Week 1 Wednesday (JS)
- **variable**: container that is used to store data.
- **value**: piece of data and information that has your code work.
- **string**: text that are wrapped in quotation marks. 

## Week 1 Thursday (JS) 
- **let**: makes a variable so it can be changed later.
- **number**: a value that is written without quotes.
- **boolean**: can either be true or false.

## Week 2 Monday (HTML)
- **section**: element that groups its related things to one specific part of the page.
- **heading**: a title part for a page.
- **button**: something people can click that is an element.

## Week 2 Tuesday (CSS)
- **padding**: inside area of the border and content.
- **border**: the border around the content.
- **margin**: outside area of the content between other elements.

## Week 2 Wednesday (JS)
- **DOM**: a browsers live copy of your page that JS can change.
- **queryselector**: searches for the first element that matches with a CSS selector.
- **textContext**: text that is inside an element.

## Week 2 Thursday (JS)
- **template literal**: special string that JS uses backticks that include variables.
- **backtick**: ` ends and starts template literal.
- **placeholder**. ${} within a template literal thats replaced by a variables value.

## Week 3 Monday (HTML & CSS)
- **id**: identifier used to target a single specific element on a webpage.
- **id selector**:identifer used to target and style a specific element on a webpage.

## Week 3 Tuesday (CSS)
- **psuedo-class**: lets you change how an element looks.
- **hover**: when your resting your mouse over the element.
- **cursor**: your mouse pointer.

## Week 3 Wednesday (JS)
- **function**: reuseable set of instructions.
- **call**: tells JS to run the instructions.
- **function body**: instructions that are inside a function.

## Week 3 Thursday (JS)
- **event**: something that happens on a page.
- **event listener**: listens for a specific event.
- **addEventListener**: attaches event to handler.

## Week 4 Tuesday (CSS)
- **transition**; makes it so the style change happens slower rather than instantly.
- **duration**; the amount of time something takes. 

## Week 4 Wednesday (JS)
- **console**; a secret/hidden panel hidden in the browser for the developer to see messages.
- **console.log**; writes a message in the console.

## Week 4 Thursday (JS)
- **counter**; variable that goes up by one each time something happens. It helps to count.
